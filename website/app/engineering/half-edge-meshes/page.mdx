# Half-edge meshes

Slab keeps a watertight volume on each `SlabSolid`. Every edge has a twin. Walk a face, then hop the twin, and you are on the neighbour. Extrude, inset, bevel, and boolean all assume that hop exists.

A triangle list does not give you that hop. You can draw it. You cannot ask "which face is across this edge" without building the adjacency again.

## Why half-edge, not winged-edge

Winged-edge stores more pointers per edge and grew up around manifold polyhedra for CAD. Half-edge splits each undirected edge into two directed records. The split is cheaper to walk in code, and it is the form most mesh libraries still ship.

Guibas and Stolfi set down the primitives as a quad-edge algebra. Slab does not implement quad-edge. It uses the same idea: an edge record knows its origin, its next edge around the face, and its twin.

Baumgart's winged-edge paper is the older computer-vision source. Weiler later compared edge-based schemes for solid modelling. Those three are enough if you want the data structure without reading a graphics textbook.

## What Slab stores on a face

Each face carries a UV scale, offset, rotation, a projection axis, and a material slot. The slot is an integer 0 to 31. The emitted mesh is still one surface today. The slot is data on the face, not a second material in the inspector.

The click path picks one solid, then an element on that mesh. Two nodes are two meshes until you boolean them. See [Closed solids](/guide/explanation/closed-solids) for the product rule.
