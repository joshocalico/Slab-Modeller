# The guide

This site is the Slab manual. Pick a page by the job you have.

- New to Slab. Start with [Install Slab](/guide/install), then [Block out a room](/guide/tutorials/block-out-a-room).
- You already have a solid selected. Use the how-to pages. [Create a solid](/guide/how-to/create-a-solid) if you still need a volume. [Select in the 3D view](/guide/how-to/select-in-the-view) to pick and move. [Pull a wall](/guide/how-to/pull-a-wall) or [Punch a cavity](/guide/how-to/punch-a-cavity) for the common edits. [Paint texture pixels](/guide/how-to/paint-texture-pixels) for albedo marks that survive reopen. [Texture a room](/guide/tutorials/texture-a-room) if the gray prototype is no longer enough. [Build a house](/guide/tutorials/build-a-house) for an Arch roof, Union, and three materials.
- You want a key, a button, or a rule. Use [Keys and modes](/guide/reference/keys-and-modes), [The Slab panel](/guide/reference/panel), and [Nodes and output](/guide/reference/nodes-and-output).
- You want the why. Read [Closed solids](/guide/explanation/closed-solids).
