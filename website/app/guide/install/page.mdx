# Install Slab

Install the prebuilt addon ZIP into a Godot 4.7 project. You do not need Python, SCons, or a C++ compiler to use the download.

## Download the addon

Open [Slab releases](https://github.com/joshocalico/slab-modeller/releases) and download **slab-addon.zip** from the release assets. The GitHub **Source code** downloads do not contain compiled libraries.

If no release is published, or you want a development build:

1. Sign in to GitHub and open [Slab's Actions runs](https://github.com/joshocalico/slab-modeller/actions).
2. Select a successful **Build drop-in addon** run. Choose a run from the `main` branch.
3. Under **Artifacts**, download **slab-addon**.
4. Extract that download to find **slab-addon.zip** and **SHA256SUMS**. The enclosed `slab-addon.zip` is the installable addon.

Actions artifacts expire after 30 days. If a download has expired, choose a newer successful run. Release assets are the preferred download once a release is published.

The same addon ZIP includes libraries for Windows x64, Linux x64, and macOS Intel and Apple Silicon. Both editor/debug and release/export libraries are included. Android, iOS, Web, and Windows/Linux ARM builds are not included.

## Add Slab to your project

1. Save your work and close the target project in Godot.
2. Extract **slab-addon.zip** into the project root, beside `project.godot`.
3. Check that the files have this layout:

   ```text
   your-project/
     project.godot
     addons/
       slab/
         plugin.cfg
         slab.gdextension
         bin/
         ...
   ```

4. Open the project in Godot 4.7 and wait for importing to finish.
5. Open **Project → Project Settings → Plugins** and enable **Slab**.
6. Open or create a 3D scene with a `Node3D` root. Click the **Slab** bottom panel.
7. In Object mode, choose **Box**, click **Create**, then click in the 3D view to place it.

The box should appear in the scene and remain editable through Slab. Continue with [Block out a room](/guide/tutorials/block-out-a-room).

Copy the complete `addons/slab/` directory. Keep the scripts, icons, extension descriptor, and `bin/` libraries together. The addon ZIP does not include the demo scenes or demo materials from the source project.

## Update an existing installation

1. Save and back up your project, then close Godot.
2. Replace `addons/slab/` with the directory from the new addon ZIP. Keep your scenes and painted textures outside the addon directory.
3. Reopen the project, wait for importing, and confirm that Slab is enabled under **Plugins**.

Do not mix scripts from one build with libraries from another.

## Build from source instead

Use this path if you are developing Slab or need to compile a library yourself.

1. Install Git, Python 3, SCons, and a C++ compiler. On macOS, install the Xcode Command Line Tools. On Linux, use GCC or Clang. On Windows, use a MinGW-w64 shell with GCC and SCons; Slab's exact geometry predicates require `__int128`, which MSVC does not support.
2. Clone the [Slab repository](https://github.com/joshocalico/slab-modeller) with its submodule:

   ```bash
   git clone --recurse-submodules https://github.com/joshocalico/slab-modeller.git
   cd slab-modeller
   ```

3. Build the editor and export libraries. On macOS or Linux, run:

   ```bash
   scons target=template_debug -j4
   scons target=template_release -j4
   ```

   On Windows, run these commands from the MinGW-w64 shell:

   ```bash
   scons platform=windows arch=x86_64 use_mingw=yes target=template_debug -j4
   scons platform=windows arch=x86_64 use_mingw=yes target=template_release -j4
   ```

4. Open `project/` in Godot 4.7 and enable Slab under **Plugins**, or copy the complete `project/addons/slab/` directory into another project's `addons/` directory.
5. To explore the bundled demo, open `demo/demo.tscn` in the source project.

For an existing checkout, run `git submodule update --init --recursive` before building. Compiled libraries go under `project/addons/slab/bin/`. Do not rename them; their paths must match `slab.gdextension`.

If you change Slab itself, run `scripts/slab-verify` on the macOS development path. It rebuilds the extension and kernel tests, then runs the kernel and Godot checks. Installation from the ZIP does not require this step.

## Fix a failed installation

- **Slab is absent from Plugins:** check for `<your-project>/addons/slab/plugin.cfg`. If you have an extra `slab-addon/` folder around `addons/`, move `addons/` beside `project.godot`.
- **The ZIP contains another ZIP:** you downloaded the Actions artifact wrapper. Extract the enclosed `slab-addon.zip` into your project.
- **Godot cannot load the library or find SlabSolid:** confirm that you downloaded the addon asset, not GitHub's source archive. Check that `addons/slab/bin/` contains the library for your operating system and architecture, then restart Godot. Read the GDExtension load error if it still fails.
- **The addon stops loading after an update:** replace the complete addon directory from one ZIP, then restart Godot.
- **A source build reports `godot-cpp is missing`:** run `git submodule update --init --recursive` from the repository root.
- **A source build cannot find SCons:** install it with `python -m pip install scons`, or use your MinGW-w64 package manager on Windows, then check `scons --version` in the build shell.
