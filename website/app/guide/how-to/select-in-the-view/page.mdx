# Select in the 3D view

Use this when a solid is in the scene and you need to pick objects or mesh elements.

## Switch mode

Click **Object**, **Vertex**, **Edge**, or **Face** in the Slab header. With the 3D viewport focused, the corresponding shortcuts are <kbd>1</kbd>, <kbd>2</kbd>, <kbd>3</kbd>, and <kbd>4</kbd>. After editing a panel field, use the mode buttons or click the viewport before using shortcuts. Both mode strips stay in sync. Changing mode clears the element selection.

## Click to select

With Surface Paint closed, click a solid in the 3D view. In Object mode that focuses the node. In Vertex, Edge, or Face mode the click also picks the nearest element under the cursor.

Shift, Ctrl, or Cmd click adds or removes that element. A double-click on an edge selects the edge loop.

<kbd>A</kbd>, Grow, Invert, Select Loop, and Select Ring also change the set. Expand **Selection** for Grow and Invert. Select Loop and Select Ring stay in the open Edge group; Select Ring follows the parallel edges across quads.

To select the edges around a face region, select its faces and choose **Select Boundary**. Slab switches to Edge mode and selects the outer edges, excluding edges shared by two selected faces. Selecting every face of a closed solid leaves no boundary.

## Move the selection

To edit a light, camera, or another authored node, select it in Godot's Scene tree. Slab clears its solid and element selection, including when that node is a child of a `SlabSolid`. Edit the node with Godot's Inspector and transform tools. Select the solid again to resume modelling.

Click without moving the mouse still selects. Motion under 6 pixels is still a click.

Choose Godot's Move, Rotate, or Scale tool in the 3D toolbar. <kbd>W</kbd> selects Move and <kbd>R</kbd> selects Scale. In Face mode Slab reserves <kbd>E</kbd> for Extrude, so choose Rotate from the toolbar there. The gizmo transforms every vertex represented by the selected vertices, edges, or faces in one validated edit. A plain drag is left for that gizmo, so the view can still orbit.

## Place and orient the gizmo

Use **Pivot** in the Slab panel to place the handle at the selection centre, the active element, or an exact custom world position. The active element is the last element added to the selection.

Use **Axes** to choose world axes, the solid's local axes, or the selected face's axes. Face axes use the active selected face and are available only in Face mode. Slab keeps these axes orthogonal under a nonuniform node scale.

Each completed gizmo drag is one undo action. A transform that would collapse or invalidate the solid is refused and leaves the last valid mesh unchanged.

## Use operation handles

Select faces and click **Extrude** or **Inset**, or select edges and click **Bevel**. Slab renders the proposed geometry and shows a separate coloured handle with its current measurement. The preview is temporary until you apply it.

Drag the handle to change the value. For an exact value, type **Extrude distance**, **Inset distance**, or **Bevel width**. Bevel also exposes **Segments**. Click **Apply** or press Enter to commit one undo action. Click **Cancel**, press Escape, or right-click to leave the solid unchanged.

Extrude uses an arrow along the face normal. Inset uses a width marker across the face boundary. Bevel uses an arc across the selected edge. If the proposed mesh is invalid, Slab restores the original solid and disables **Apply**.

Saving while an operation preview is open leaves the preview active but does not save its proposed geometry. Click **Apply**, then save the scene to keep the result.

Extrude, Inset, and Bevel remember separate last-used distances for the editor session. Cancelling retains the adjusted setting even though it discards the preview. Undo restores committed geometry and does not rewind these preferences.

Shift-drag remains a direct gesture: Shift-drag a face to extrude it, or Shift-drag an edge to bevel it. Release commits the grab. Escape during the drag restores the mesh and keeps the current mode.

## Pick through the solid

Enable **X-ray selection** to include occluded vertices, edges, and faces on visible solids. The candidates and wire display remain visible through the solid. Press <kbd>Tab</kbd> to cycle candidates under the pointer and <kbd>Shift</kbd>+<kbd>Tab</kbd> to cycle backward, then click to select the highlighted candidate. Turn X-ray off to restrict picking and highlights to visible geometry.

X-ray does not include a node hidden in Godot or a node under a hidden ancestor. Hide an obstructing `SlabSolid` to pick the visible geometry behind it. To show the solid again, select it in the Scene tree and enable **Visibility > Visible** in the Inspector.

## Keep a multi-selection when you move

A plain click replaces the element set with the item under the cursor. Shift-click to add faces, then use the Move gizmo. Shift-drag on faces also extrudes.

Shift-drag on edges bevels the set. To translate edges, use the Move gizmo.

Element selection stays on one solid. Object mode can add solids to the editor selection with Shift click.

## Select while painting

To change the selected face set without painting, click **Face** to leave Surface Paint, select the faces, then reopen **Surface Paint**.

In **Material / UV**, a plain face click applies the current Brush. To inspect another face without assigning that Brush, Alt-click the face to sample its material and UV values. With Brush empty, the first plain click selects and adopts the face's existing material without editing it. A default-material face is selected but leaves Brush empty.

In **Pixel**, a face click starts a pixel stroke on that face's image. Select the intended faces before entering Pixel. See [Paint texture pixels](/guide/how-to/paint-texture-pixels) for shared-material preparation.

Unmodified clicks and drags in empty space preserve the Paint target. To return to modelling, click a mode button. Escape cancels an active stroke or UV drag first; with no gesture active, it closes Surface Paint.
