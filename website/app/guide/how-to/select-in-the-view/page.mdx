# Select in the 3D view

Use this when a solid is in the scene and you need to pick objects or mesh elements.

## Switch mode

Press <kbd>1</kbd>, <kbd>2</kbd>, <kbd>3</kbd>, or <kbd>4</kbd> for Object, Vertex, Edge, or Face. The strip in the spatial editor menu and the strip in the Slab panel stay in sync. Changing mode clears the element selection.

## Click to select

Click a solid in the 3D view. In Object mode that focuses the node. In Vertex, Edge, or Face mode the click also picks the nearest element under the cursor.

Shift, Ctrl, or Cmd click adds or removes that element. A double-click on an edge selects the edge loop.

A, Grow, Invert, Select Loop, and Select Ring on the panel also change the set. Those icons follow the current mode. Select Ring follows the parallel edges across quads.

## Move the selection

Click without moving the mouse still selects. Motion under 6 pixels is still a click.

Choose Godot's Move, Rotate, or Scale tool in the 3D toolbar. <kbd>W</kbd> selects Move and <kbd>R</kbd> selects Scale. In Face mode Slab reserves <kbd>E</kbd> for Extrude, so choose Rotate from the toolbar there. The gizmo transforms every vertex represented by the selected vertices, edges, or faces in one validated edit. A plain drag is left for that gizmo, so the view can still orbit.

## Place and orient the gizmo

Use **Pivot** in the Slab panel to place the handle at the selection centre, the active element, or an exact custom world position. The active element is the last element added to the selection.

Use **Axes** to choose world axes, the solid's local axes, or the selected face's axes. Face axes use the active selected face and are available only in Face mode. Slab keeps these axes orthogonal under a nonuniform node scale.

Each completed gizmo drag is one undo action. A transform that would collapse or invalidate the solid is refused and leaves the last valid mesh unchanged.

## Use operation handles

Select faces and click **Extrude** or **Inset**, or select edges and click **Bevel**. Slab shows the proposed result and a separate coloured handle with its current measurement.

Drag the handle to change the value. For an exact value, type **Extrude distance**, **Inset distance**, or **Bevel width**. Bevel also exposes **Segments**. Click **Apply** or press Enter to commit one undo action. Click **Cancel**, press Escape, or right-click to leave the solid unchanged.

Extrude uses an arrow along the face normal. Inset uses a width marker across the face boundary. Bevel uses an arc across the selected edge. If the proposed mesh is invalid, Slab shows the refused geometry and does not enable a bad commit.

Shift-drag remains a direct gesture: Shift-drag a face to extrude it, or Shift-drag an edge to bevel it. Release commits the grab. Escape during the drag restores the mesh and keeps the current mode.

## Pick through the solid

Enable **X-ray selection** to include occluded vertices, edges, and faces. The candidates and wire display remain visible through the solid. Press <kbd>Tab</kbd> to cycle candidates under the pointer and <kbd>Shift</kbd>+<kbd>Tab</kbd> to cycle backward, then click to select the highlighted candidate. Turn X-ray off to restrict picking and highlights to visible geometry.

## Keep a multi-selection when you move

A plain click replaces the element set with the item under the cursor. Shift-click to add faces, then use the Move gizmo. Shift-drag on faces also extrudes.

Shift-drag on edges bevels the set. To translate edges, use the Move gizmo.

Element selection stays on one solid. Object mode can add solids to the editor selection with Shift click.
