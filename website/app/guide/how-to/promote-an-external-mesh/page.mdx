# Promote an External mesh

Use **Promote to Slab Solid** when an imported mesh is already a closed solid and you want Vertex, Edge, Face, UV, and Paint tools. Import never promotes on its own.

**Promote** appears only when Object mode has exactly one External mesh selected. It is hidden for a SlabSolid, an empty selection, or a multi-select.

<video controls preload="metadata" width="100%" src="/videos/v1/v1-07-import-external.mp4"></video>

The clip shows **Import Mesh…**, the External badge, topology staying off, and an Export round trip. **Promote** appears for one selected External mesh; it checks whether the geometry can become a closed solid.

## Idle External mesh

1. Press <kbd>1</kbd> for Object mode.
2. Import a mesh, or select an existing External mesh.
3. The header shows a badge: `(External mesh)`.
4. Vertex, Edge, and Face stay disabled. So do UV and Paint. Their tooltip reads `Convert to a Slab solid first…`

**Import Mesh…** and **Export…** stay available. Object move, rotate, and scale stay available.

![External mesh selected in the Object panel with Promote to Slab Solid available](/img/panel-external.png)

## Promote

1. Keep the External mesh selected in Object mode (one External only).
2. Click **Promote to Slab Solid**. It sits with Import and Export.

On success the badge clears and topology modes unlock. The solid retains the mesh's supported UVs, material slots, active material overrides, transform, visibility, and child nodes. Undo restores the External mesh and its children.

## Refuse

Promote does not repair the mesh. If the soup is empty, open, or non-manifold, the External mesh stays as it is. Status names the reason, for example `Could not promote: mesh is open. External mesh unchanged.` There is no partial convert.

Promote also refuses data it cannot preserve, including blend shapes, skin weights, secondary UVs, vertex colors, and material overlays. A direct child named `Mesh` or `__body` conflicts with the generated solid children and also prevents conversion.

Fix the mesh in the source file, or keep it as External and export it as a triangle mesh.

See [Closed solids](/guide/explanation/closed-solids) for why Slab refuses an open sheet.

## Import an OBJ with materials

Keep the OBJ, its MTL library, and its albedo textures together. Import reads material groups, diffuse color, transparency, and plain albedo texture paths. A missing MTL library, undefined material, missing texture, or unsupported texture option is refused with a reason. STL imports geometry without materials.
