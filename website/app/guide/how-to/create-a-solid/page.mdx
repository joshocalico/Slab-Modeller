# Create a solid

Use this when the scene has no `SlabSolid` yet, or when you want a second volume as a cutter.

## Make a box

1. Press <kbd>1</kbd> for Object mode.
2. Click **Box** in **Create**.
3. Leave **Width**, **Height**, and **Depth** at 2 m, or set the dimensions you need.
4. Click **Create**.

A `SlabSolid` appears with its local origin at the box's minimum corner. The box extends from there along positive X, Y, and Z. The selected shape and values remain ready for another **Create**. Changing them does not resize an existing solid.

## Other shapes

Choose a shape to show its fields. Set the fields, then click **Create**. The shape and its values remain selected, so another click on **Create** makes another solid with the same parameters. No selection is required.

| Shape | What you get |
| --- | --- |
| **Plane** | A Width × Depth slab. Thickness is one grid step. |
| **Stair** | A straight run of Steps steps. Default 8. |
| **Cylinder** | A cylinder with Sides sides. Width is the diameter. Its local origin is the base centre, and it extends along positive Y. Default 16 sides. |
| **Arch** | A band swept through Arc. Default 180°, 8 segments, 0.25 m thick. A 90° arch is narrower than Width. A 360° arch is a closed ring. |
| **Poly Shape** | A Width × Depth square extruded to Height. |
| **Curve Sweep** | A Width × Height profile swept along a path. |

To size a box after you create it, switch to Face mode and use the Move gizmo. See [Pull a wall](/guide/how-to/pull-a-wall).

## Live sweep path

**Curve Sweep** on the panel is a one-shot solid. For a path you can edit, add a `SlabSweep` node. Set **Points** along the floor. **Profile** is width and height. The node rebuilds a mesh as you change those fields. It is not a `SlabSolid`. Boolean and the Slab panel do not edit it.
