# Prepare a solid for runtime

Use editable `SlabSolid` nodes directly in a scene, or build one combined mesh from a `SlabModule` in code.

<video controls preload="metadata" width="100%" src="/videos/v1/v1-06-export-mesh.mp4"></video>

**Export…** writes GLB, glTF, OBJ, STL, or FBX from a selected solid or External mesh. It does not change the scene. The clip above shows the dialog and an OBJ save.

For GLB or glTF, choose **Export…** and save the default `.glb` file or select `.gltf`. These formats retain supported materials, both UV channels, vertex colors, skin bindings, and blend shapes from the current generated mesh. Keep a glTF file with its adjacent assets directory. GLB packages the export in one file. Godot shader materials are refused. Keep the Godot scene for collision, construction history, and Godot-specific material effects such as heightmap parallax.

For OBJ, STL, or FBX, export bakes the selected objects' transforms into triangle geometry. OBJ retains UVs, normals, material groups, and StandardMaterial3D albedo color and transparency. It writes an MTL file and albedo PNG dependencies beside the OBJ. Keep those files together when moving the export.

OBJ does not export roughness, emission, normal maps, or shader behavior. Unsupported material classes and unreadable textures are refused. FBX retains geometry, UVs, normals, and material names but does not copy textures or Godot material settings. STL contains geometry only.

## Save editable solids

1. Keep each `SlabSolid` in the edited scene tree.
2. Save the scene.
3. Close and reopen the scene.
4. Select a solid and enter Face mode to confirm that its faces remain editable.

The `SlabSolid` stores its half-edge data and material slots. Its internal `Mesh` and `__body/__shape` children are generated output. Do not edit or move those children.

## Test collision

1. Select the `SlabSolid` in the scene tree.
2. Leave **Collision Enabled** on for floors, walls, and other static level geometry.
3. Run the scene and test it with the player or another physics body.
4. Return to the editor, change the solid, and run the scene again.

Slab rebuilds the visible mesh and its concave `StaticBody3D` collision after every geometry edit. Turn **Collision Enabled** off for decorative solids or when another node owns collision.

## Build a combined module mesh

Call `bake_mesh()` when code needs one `ArrayMesh` from the direct `SlabSolid` children of a `SlabModule`:

```gdscript
var baked: ArrayMesh = $SlabModule.bake_mesh()
$MeshInstance3D.mesh = baked
```

The baked mesh applies each direct child's transform and combines positions, normals, UVs, and triangle indices. It omits nested solids, sockets, collision, and material assignments. Keep the original module when you still need editable geometry or those omitted parts.

Save any resource created from the returned mesh with Godot's `ResourceSaver` if it must persist outside the running scene. See [Nodes and output](/guide/reference/nodes-and-output) for the complete node contract.
