# Pull a wall

Use this when a face is already there and you want it farther out.

## Move the face

1. Press <kbd>4</kbd> for Face mode.
2. Click the face.
3. Press <kbd>W</kbd> so the editor is in Move mode.
4. Drag an axis of the gizmo.

The face translates with the gizmo. It is not locked to the face normal.

## Extrude with the operation handle

1. Select one or more faces.
2. Click **Extrude**, or press <kbd>E</kbd>.
3. Drag the cyan arrow along the face normal, or type an exact **Distance**.
4. Click **Apply** or press Enter.

Positive values move outward. Negative values move inward. Click **Cancel**, press Escape, or right-click to discard the preview. Apply creates one undo action.

## Extrude by dragging

Hold Shift, click a face, and drag past the threshold. Slab extrudes once at the start of the drag, then moves the new cap with the cursor. The original ring stays as the base.

## Inset instead of pull

Select the face and click **Inset**, or press <kbd>I</kbd>. Drag the gold width marker or type an exact **Distance**, then Apply. Inset shrinks a copy of the face on the same plane and uses the absolute distance. A refused preview leaves the solid unchanged.
