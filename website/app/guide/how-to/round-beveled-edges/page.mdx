# Round beveled edges

Use a segmented bevel to soften a blockout edge, round a face perimeter, or round the three edges that meet at a corner.

## Preview a bevel

1. Select a `SlabSolid` and switch to Edge mode.
2. Select one or more edges, then choose **Bevel**.
3. Drag the purple width arc, or set **Bevel width** to the exact distance removed from each adjoining face.
4. Set **Segments** from 1 to 16. One segment is a straight chamfer; additional segments follow a rounded profile.

For a face perimeter, start in Face mode, select the face, and choose **Select Boundary**. Then choose **Bevel**. For example, a 4.4 × 0.2 × 4.4 roof accepts width 0.03 and three segments around its top face.

The rendered preview shows the exact validated result while the original solid remains unchanged. Three selected edges meeting at one corner create a closed corner patch before their rounded edge bands are built. If a value is invalid, Slab restores the original display and disables **Apply**.

A simple connected perimeter is supported where each corner has three incident edges and two selected edges. A complete box-edge selection is still unsupported. Cancel that preview and choose a smaller edge set; reducing the width does not resolve an unsupported arrangement.

## Apply or cancel

Press Enter or click **Apply** to commit the preview as one undo action. Click **Cancel**, press Escape, or right-click to restore the original display and leave the solid unchanged. Saving while the preview is open does not save the proposed bevel. Apply it, then save the scene to keep the result. If the solid changes while the preview is open, the tool cancels rather than applying stale edge handles.

Bevel remembers its last width for the editor session, including a width from a cancelled preview. Undo restores geometry and does not change that preference. Extrude and Inset keep separate remembered distances.

Very small amounts with many segments can collapse several samples onto the same lattice point. Slab refuses that result; increase the amount or reduce the segment count.

After beveling a connected selection, recheck UV seams on shortened or replaced edges. Unchanged edges retain their seam marks; modified edges do not currently inherit them.
