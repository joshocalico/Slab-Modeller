# Unwrap faces at a consistent texel density

Use this when adjoining faces should paint continuously and keep texture pixels the same physical size.

<video controls preload="metadata" width="100%" src="/videos/v1/v1-04-uv-unwrap-fit.mp4"></video>

1. In Edge mode, select the edges where the texture may split and click **Mark Seam**. Use **Clear Seam** to remove a mark.
2. Switch to Face mode and select the faces to unwrap.
3. Click **UV** in the Slab header. In **Mapping**, set **Pixels/metre** to the detail you need.
4. Set **Texture px** to the material texture's width in pixels.
5. Click **Unwrap**.

Slab unfolds across edges that are not seams. Marked seams start separate islands. It packs the islands apart with a one-pixel gap.

Every island must fit once inside the texture tile. Slab never shrinks the requested density or relies on texture wrapping to hide overlap. If the atlas is too large, the solid stays unchanged and Slab asks for a larger texture or a lower pixels-per-metre value.

A closed or branching patch sometimes cannot lie flat without crossing itself. Slab adds seams where a cycle cannot close or two branches would overlap, and reports the automatically cut edges. Those seam marks persist with the solid, so review them before painting.

The UV canvas frames the new layout after Unwrap. Undo and Redo also frame a restored layout. Placement changes keep your canvas view steady while you move, rotate, or scale the mapping. Use **Fit UV** to frame the outlines again after placement edits. Fit UV only changes the canvas view. It does not move islands.

After placement, click **Pack** to re-atlas the existing islands without unfolding them again. The tooltip is `Repack islands without re-unwrapping.` If the islands no longer fit, Pack refuses, leaves the solid unchanged, and asks you to raise **Texture px** or scale down **Placement**.

Unwrap resets Repeat U, Repeat V, Offset and Rotation so the requested density is exact. Pack also resets those fields after it bakes the new atlas. Apply placement afterward if an island needs to move, turn or repeat.

Each face stores the texture resolution used for its mapping. Pack preserves its pixel density when you change **Texture px**, switch solids, undo, or reopen the scene. Faces unwrapped at different resolutions keep their own densities when packed together.

Older scenes do not contain this resolution. Their first Pack keeps the current UV scale and adopts **Texture px** as the source resolution. To set an exact density for an older mapping, choose **Pixels/metre** and **Texture px**, then Unwrap again.

Paint mode hides the UV element strip, Unwrap, and Pack. Soft Select stays with modelling and does not appear in the UV workspace.

For example, 256 pixels per metre on a 1024-pixel texture maps one metre of mesh surface to 0.25 UV units.

Save the scene after unwrapping. Seam marks, unfolded coordinates, and the scale derived from **Pixels / metre** and **Texture px** are stored in the `SlabSolid` data and follow ordinary undo and redo.

If the material has no image yet, switch to **Paint** and set **New image px** before **Make Unique**. The new paint image uses that size. Existing artwork keeps its current dimensions, and selecting it updates **Texture px** to its width. Changing the reference resolution in Mapping does not resize an existing image.


## Keep UV points fixed

1. Choose **UV Vert**, **UV Edge**, or **UV Face** on the UV canvas.
2. Select the elements to hold in place.
3. Choose **Tools → Pin**.
4. Run **Unwrap** or **Pack**.

Pinned corners stay at their UV coordinates. Pack places other islands around pinned islands. If the density, resolution, or layout cannot satisfy the pins, the operation refuses and leaves the solid unchanged. Select the pinned elements and choose **Tools → Unpin** before making a conflicting change.

## Relax an island

1. Select UV elements in the area to relax.
2. Choose **Tools → Relax**.
3. Inspect the result and undo if necessary.

Relax keeps seams, selection boundaries, and pinned corners fixed. To return selected UV faces to projected mapping, choose **Tools → Reset projection**. Unpin those faces first if their pins prevent the reset.

## Stitch two islands

1. Choose **UV Edge**.
2. Select one side of a shared mesh edge on the island that should stay fixed.
3. Shift-click the opposite side on the other island.
4. Choose **Tools → Stitch**.

Stitch moves, rotates, and scales the second island to match the first edge, then clears that seam. Unpin the moving island if a pin prevents the operation.

## Align islands

1. Select UV elements in at least two islands.
2. Choose a **Tools → Align** command for the desired edge or center.

Alignment translates whole islands and preserves their shapes. Unpin an island before an alignment that would move its pinned corners. Click **Pack** afterward if the aligned islands overlap.
