# Meet the Slab editor

Create a box, edit one face through a preview, and undo the edit. This short tour establishes the workflow used throughout the guide.

## Create a box

1. Open the **Slab** bottom panel.
2. Click **Object** in the Slab header.
3. Click **Box** in **Create**. Its default **Width**, **Height**, and **Depth** are 2.
4. Click **Create**.
5. Move the gold preview over the world ground plane.
6. Click to place it, or press Enter.

The status names the selected solid. To cancel a placement preview, press Escape or right-click. Object mode moves the whole `SlabSolid` with Godot's transform gizmo.

## Select a face

1. Click **Face** in the Slab header.
2. Click the top face.

The status reports one selected face. Vertex, Edge, and Face modes change which mesh elements a click can select. With the 3D viewport focused, press <kbd>1</kbd>, <kbd>2</kbd>, <kbd>3</kbd>, or <kbd>4</kbd> to change mode. When a panel field has focus, use the mode buttons or click the viewport before using shortcuts.

## Preview and apply an edit

1. In **Face**, click **Extrude**, or press <kbd>E</kbd>.
2. Set **Extrude distance** to 0.5, or drag the coloured handle in the 3D view.
3. Inspect the preview.
4. Click **Apply**, or press Enter.

Starting the command renders the proposed geometry without changing the saved solid. **Apply** commits the preview as one undo action. To restore the original display and discard the proposal, click **Cancel**, press Escape, or right-click. Saving before Apply does not save the preview; apply the edit, then save the scene.

## Undo and continue

Press <kbd>Ctrl</kbd>+<kbd>Z</kbd>, or <kbd>Cmd</kbd>+<kbd>Z</kbd> on macOS. The box returns to its earlier shape and Slab restores the face selection.

The same pattern applies to Inset and Bevel: choose the mode, select elements, start the command, adjust the preview, then apply it. Disabled commands need a different mode or selection. Point at a disabled command to read its requirement.
