# Keys and modes

Mode keys fire even when nothing is selected. They stop in the 3D view so Godot does not treat them as numpad emulation.

## Modes

| Key | Mode | What a click does |
| --- | --- | --- |
| <kbd>1</kbd> | Object | Focus a `SlabSolid`. The node Move gizmo transforms the solid. Drag does not move vertices. |
| <kbd>2</kbd> | Vertex | Pick a vertex. Move, Rotate, and Scale transform the selection around the configured pivot and axes. |
| <kbd>3</kbd> | Edge | Pick an edge. The transform gizmo acts on both endpoints. Shift-drag bevels. Double-click selects the edge loop. |
| <kbd>4</kbd> | Face | Pick a face. The transform gizmo acts on all its vertices. Shift-drag extrudes. |
| <kbd>Escape</kbd> | Object | Leaves element mode. During a Shift-drag, Escape cancels the grab and does not change mode. In Surface Paint it cancels a stroke, or closes the workspace when idle. |

<kbd>W</kbd>, <kbd>E</kbd>, and <kbd>R</kbd> are Godot's Move, Rotate, and Scale tools. Slab claims <kbd>E</kbd> in Face mode for Extrude when a face is selected.

## View

| Input | Result |
| --- | --- |
| Click | Select. Shift, Ctrl, or Cmd toggles. |
| Drag past 6 pixels | Without Shift, the editor Move gizmo keeps the event. Shift-drag extrudes a face or bevels an edge. The view cannot orbit until that grab releases. |
| Hover with no buttons | Pass. Orbit still works. |
| Miss in element mode with a solid selected | Clear element ids. Keep the solid. |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | Cycle forward or backward through candidates under the pointer when X-ray selection is enabled. |

## Panel shortcuts

These run only when the current mode and selection count match the command. They fire from the 3D view whether or not the Slab dock is open.

| Key | Command | Mode |
| --- | --- | --- |
| <kbd>A</kbd> | Select All | Vertex, Edge, Face |
| <kbd>D</kbd> | Select None | Vertex, Edge, Face |
| <kbd>E</kbd> | Extrude | Face |
| <kbd>I</kbd> | Inset | Face |
| <kbd>B</kbd> | Bevel | Edge |
| <kbd>L</kbd> | Loop Cut | Edge |
| <kbd>X</kbd> | Dissolve | Edge |
| <kbd>G</kbd> | Bridge | Edge |
| <kbd>K</kbd> | Connect | Vertex or Edge |
| <kbd>J</kbd> | Weld | Vertex |
| <kbd>Y</kbd> | Collapse | Vertex |
| <kbd>U</kbd> | Subdivide | Face |
| <kbd>M</kbd> | Merge | Face |
| <kbd>N</kbd> | Flip Normals | Face |
| <kbd>Delete</kbd> | Delete | Face |

Select Ring, the Create icons, and the Object boolean icons have no keys.

<kbd>A</kbd> through those keys are ignored when Ctrl or Cmd is held, so editor chords still pass through.

Surface Paint takes keyboard input while it is open, so modelling mode and command keys do not run there.

Extrude, Inset, Bevel, Plane Cut, Array, Loop Cut, Snap to Vertex, and Align Face are modal previews. Drag an operation handle or use its numeric field, then press Enter or click Apply. A left click chooses the target for Snap or Align. Escape, right-click, or Cancel closes a preview without applying it.
