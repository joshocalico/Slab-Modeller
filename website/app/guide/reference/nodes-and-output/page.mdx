# Nodes and output

## SlabSolid

`SlabSolid` stores the editable half-edge data, materials, grid step, prototype colour, and collision switch. Its generated children are implementation output:

| Child | Output |
| --- | --- |
| `Mesh` | An `ArrayMesh`, split into surfaces by face material slot. |
| `__body/__shape` | A `StaticBody3D` with a concave triangle-soup shape. |

`collision_enabled` defaults to `true`. Every geometry rebuild refreshes the concave collision while it is enabled. Turning the property off disables the collider without replacing the visible mesh; the next geometry rebuild clears the shape. Turn it off for decorative or separately managed solids.

`build_mesh()` returns the current `ArrayMesh`. It preserves the solid's material-slot surfaces.

Editing methods return `0` on success and a mesh error code when refused. The current API includes region-aware `extrude_faces()` and `inset_faces()`, segmented `bevel_edges()`, `insert_loops()`, `plane_cut()`, seam marking and UV unwrapping. `preview_bevel()`, `preview_loop_cuts()`, and `preview_plane_cut()` return validated scratch results without mutating `data`.

`import_from_mesh(vertices, indices)` tries to replace the solid with a closed triangle soup. It returns `{ "error": 0, "refuse_reason": "" }` on success. On refuse it leaves the current solid unchanged and sets `refuse_reason` to `empty`, `open`, `non-manifold`, or `non-manifold / open`. The panel **Promote to Slab Solid…** command is the author-facing path. Import never calls this for you.

## External mesh

`SlabExternalMesh` is an imported triangle mesh. It is selectable in Object mode and can transform or export. It is not a `SlabSolid`. Vertex, Edge, Face, UV, and Paint stay disabled until **Promote to Slab Solid…** succeeds. See [Promote an External mesh](/guide/how-to/promote-an-external-mesh).

After a refusal, `get_edit_diagnostic()` returns the typed rejected location and local-space highlight segments. See [Understand refused edits](/guide/how-to/understand-refused-edits).

## SlabModule

`SlabModule` groups direct `SlabSolid` children and `SlabSocket` descriptions. `cell_size` defaults to 2 m. `get_footprint()` rounds the combined bounds up to whole cells. `module_id` defaults to `module`.

`bake_mesh()` returns one `ArrayMesh` from the module's direct `SlabSolid` children. It applies each child's local transform and combines positions, normals, UVs, and triangle indices into one surface. It does not include nested solids, sockets, collision, or material assignments.

## SlabSocket

`SlabSocket` describes a named door, open edge, or window on a module. It records a face, offset, opening size, and tags. It does not cut geometry. Use Subtract when the visible mesh needs an opening.

## SlabSweep

`SlabSweep` rebuilds a swept mesh when its points, profile, or closed setting changes. It is a `Node3D`, not a `SlabSolid`. The panel's element tools, booleans, collision switch, and `SlabModule.bake_mesh()` do not treat it as a solid.
