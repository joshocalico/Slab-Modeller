# The Slab panel

The panel is the bottom dock named **Slab**. Object mode shows a **Create strip** above the scrollable settings area: shape chips, dimension fields, and a **Create** button. The **Object** command group sits below. Vertex, Edge, and Face modes keep their geometry command group open. **Selection** in Vertex, Edge, and Face modes starts collapsed. Expand it to use its secondary commands. The panel remembers that choice while you switch selection modes. Open **Surface Paint** for materials and UVs.

Commands have icons and labels. A command disables when the selection does not meet its requirement. Point at the disabled command to read that requirement.

The header keeps the current selection visible, for example `1 face · Box`. Long names shorten with an ellipsis; the tooltip contains the full summary. The status line below shows tool instructions, results, and recovery messages without replacing the header selection.

On a wide panel, settings sit beside the command groups. On a narrow panel, settings stack below them.

## Settings

The settings area scrolls below the Create strip in Object mode. It changes with the current mode and active command. In Object mode, choose a shape to show its creation fields in the Create strip. When exactly two solids are selected, the Boolean operands appear in the scrollable settings below; the Create strip stays visible above.

| Field | When it shows | Role |
| --- | --- | --- |
| Width, Height, Depth | Object, after choosing most shapes | Size for the next **Create**. Stair shows **Run**, **Rise**, and **Width** instead. |
| Steps, Sides, Segments, Thickness, Arc | Object, after choosing Stair, Cylinder, or Arch | Only the parameters that shape reads. |
| Weld distance | Vertex, with at least 2 vertices selected | Maximum distance for Weld. Range 0.05 to 64 m. |
| Cuts, Centre % | Edge | Count and position for Loop Cut. |
| Target, Second solid, Swap operands | Object, with exactly 2 solids selected | Shows which solid receives a Boolean result and lets you exchange the operand order. The second solid is the Subtract cutter. |
| Oppose normals | Face, during Align Face | Chooses whether the source faces toward or away from the target normal. |

There is no idle Distance or Amount field for Extrude, Inset, or Bevel. Starting one of those commands replaces the idle settings with its preview controls.

## Create fields

Object mode. Choose a shape to see its fields. Changing a field never rewrites a solid that already exists. The selected shape and its values stay in the panel after creation.

| Field | Default | Range | Read by |
| --- | --- | --- | --- |
| Width | 2 m | 0.05 to 64 | Box, Plane, Cylinder, Arch, Poly Shape, and Curve Sweep. Cylinder reads it as diameter. Arch reads it as the outer sweep diameter. |
| Height | 2 m | 0.05 to 64 | Box, Cylinder, Poly Shape, and Curve Sweep. Plane and Arch ignore it. |
| Depth | 2 m | 0.05 to 64 | Box, Plane, Arch, Poly Shape, and Curve Sweep. Curve Sweep uses it as path length. |
| Run | 2 m | 0.05 to 64 | Stair. Total horizontal length along local X. |
| Rise | 2 m | 0.05 to 64 | Stair. Total height along local Y. |
| Width (Stair) | 2 m | 0.05 to 64 | Stair. Width across the steps along local Z. |
| Steps | 8 | 1 to 32 | Stair. |
| Sides | 16 | 3 to 32 | Cylinder. |
| Segments | 8 | 4 to 32 | Arch. |
| Thickness | 0.25 m | 0.05 to 8 | Arch. Must stay under half of Width. |
| Arc | 180° | 15 to 360 | Arch. Sweep centered on the crown. |

**Arc.** At 180° you get a half tube as wide as Width, both feet on the floor. Below 180° the band is narrower than Width and shorter than that half-tube. Above 180° you get a horseshoe. At 360° the ends join into a closed ring. Height is not an input. It follows Width and Arc.

## Create

Object mode. No selection required. Choose a shape, set its fields, then click **Create** to start placement. The gold preview follows horizontal Slab surfaces or the world ground plane. Its X and Z position snap to the solid's grid step. A horizontal surface keeps its exact Y position; the ground fallback uses Y = 0. Click or press Enter to place the preview. Press Escape or right-click to cancel. Changing a shape field also cancels the current preview, so click **Create** again after the change. Choose **Create** again to repeat the same shape and values.

| Shape | Result |
| --- | --- |
| Box | A box of Width × Height × Depth. Its local origin is the minimum corner, and it extends along positive X, Y, and Z. |
| Plane | A Width × Depth slab one grid step thick. |
| Stair | A straight run of Steps steps. Run follows local X, Rise follows local Y, and Width follows local Z. The stair ascends toward local +X. |
| Cylinder | A cylinder with Sides sides. Width is the diameter. Its local origin is the base centre, and it extends along positive Y. |
| Arch | A thick band swept through Arc. Width is the outer diameter. Depth is the extrusion. |
| Poly Shape | A Width × Depth square extruded to Height. |
| Curve Sweep | A Width × Height profile swept along a path whose length follows Depth. |

See [Create a solid](/guide/how-to/create-a-solid).

## Object

Boolean, Mirror, Pivot, Snap, Plane Cut, and Array need a selected `SlabSolid`. Union, Subtract, and Intersect need exactly two. **Target** receives the result. **Second solid** is the other operand and is the cutter for Subtract. Click **Swap operands** to exchange those roles before running the Boolean. The second solid remains in the scene after the operation.

**Import Mesh…** is available with no selection. **Export…** works on a selected `SlabSolid` or External mesh. **Promote to Slab Solid…** needs one External mesh.

| Command | Result |
| --- | --- |
| Union | Adds **Second solid** into **Target**. |
| Subtract | Cuts **Second solid** out of **Target**. |
| Intersect | Keeps only the overlap in **Target**. |
| Mirror X, Mirror Y, Mirror Z | Mirrors across that local axis. |
| Center Pivot | Moves the origin to the middle of the solid. |
| Snap To Grid | Rounds every vertex onto the grid step. |
| Plane Cut | Previews an exact local-space plane, keeps the chosen side, and caps every section loop. |
| Array | Previews 2 to 256 total instances in a linear or radial layout, then creates the copies as one undo action. |
| Import Mesh… | Loads an OBJ or STL as an External mesh. Non-manifold and open files stay External. Import never promotes. |
| Export… | Writes the selected solid or External mesh. Does not change the scene. |
| Promote to Slab Solid… | Converts one closed External mesh into a `SlabSolid`. Open, empty, or non-manifold meshes are refused and left unchanged. |

## Surface Paint

**Surface Paint** in the header opens a separate workspace and switches to Face mode. Escape closes it. **Material / UV** assigns materials and places the selected face on the texture. **Pixel** paints the bound Texture's albedo on the canvas or directly in the 3D view.

In **Material / UV**, **Brush** names the material that Assign and a plain viewport click will apply. The target summary separately reports the selected faces' material as a name, **Mixed**, or the default material. Opening Surface Paint with a common selected material adopts it as the Brush without assigning anything. A mixed or default-material selection opens with no assignable Brush. The Brush then stays active while you change selections inside Surface Paint.

When Brush is empty, clicking a face selects it and adopts its material and UV values without changing the solid. A default-material face remains selected while you choose a material. Once Brush is set, face clicks assign it. Left clicks and drags in empty space, without modifier keys, leave the target and scene unchanged.

In **Pixel**, **Texture** names the selected faces' common material image. Mixed-material selections have no canvas image. A 3D stroke paints the clicked face's own image; it does not assign the Material / UV brush.

Both paint tools place their controls beside the canvas and share the same minimum workspace height. Switching between **Material / UV** and **Pixel** preserves the dock height. Pixel uses a narrower control column, giving its canvas more width. Scroll the control column to reach lower settings when the dock is compact.

The gold **Surface Paint** button identifies the active workspace. The highlighted **Face** button identifies the selection mode. Click a selection-mode button to return to modelling.

### Material / UV controls

**Mapping** reports whether the selected faces use planar mapping, unwrapped mapping, or a mixture. **Unwrap** creates islands; **Placement** moves, rotates, and scales the current mapping. A successful Unwrap resets placement and frames the new islands in the canvas.

| Control | Result |
| --- | --- |
| Assign | Applies the Brush material to the selected faces. |
| Make Unique | Copies the Brush onto the selected faces and makes its albedo editable. With default-material faces, it creates a blank image. Mixed-material selections are refused. |
| Sample | Adopts the selected faces' common material as the Brush without assigning the previous Brush. Select faces using one material before sampling. Alt-click a face in the 3D view samples that face and its UV values directly. |
| Material palette | Chooses the Brush without assigning it. Click **Assign**, or click a front-facing viewport face, to apply it. |
| Material picker | Chooses or creates a `StandardMaterial3D` as the Brush preview. Click Assign to apply it to selected faces. Choosing a Brush does not change the solid or add an Undo step. Click its preview to edit the resource in Godot's Inspector. |
| Pixels/metre | Sets the density for Unwrap. |
| Texture px | Sets the reference atlas width for Unwrap. It does not resize existing artwork. |
| Unwrap | Creates seam-aware UV islands at the requested density and resets placement. An atlas that cannot fit leaves the solid unchanged and reports a suggested resolution. |
| Repeat U, Repeat V | Sets texture repeats from 0.05 to 64. |
| Repeat ×2, Repeat ÷2 | Doubles or halves both repeat values within the repeat limits and applies them in one undoable edit. Pending typed placement values are included. |
| Offset U, Offset V | Moves the texture from -64 to 64. |
| Rotation | Sets rotation from -360° to 360°. |
| Apply UV | Writes the numeric UV values to the selected face. |
| Reset UV | Returns repeats to one, offsets to zero, and rotation to zero. |
| UV 90° | Adds 90° and applies it. |

The material palette sits below the Brush picker, before Placement and Mapping. Choose a loaded material there, then click **Assign** above it.

The Material / UV canvas previews the current Brush texture beneath the selected faces' UV outlines. Choosing a palette chip updates this preview without changing the faces. **Assign** or a plain viewport click applies the Brush.

On the UV canvas, drag to move, Shift-drag to scale, and Ctrl-drag to rotate. Use Cmd-drag to rotate on macOS. Scale and rotation use screen distance independently of zoom. Shift-drag adjusts U horizontally and V vertically; rotation uses horizontal motion. Scroll zooms and middle-drag pans. See [Paint texture pixels](/guide/how-to/paint-texture-pixels).

### Pixel controls

Pixel hides Assign, Sample, the material picker, the material palette, Mapping, and the UV placement controls. Its **Image** section contains the image-size field.

| Control | Result |
| --- | --- |
| Make Unique | Copies the selected shared Texture, or creates an image for default-material faces, and assigns the owned copy to the selection. Mixed-material selections are refused. |
| Save Paint | Writes `res://slab_paint/<solid>_m<slot>.png`. It is disabled until an owned Texture is ready. Save the scene afterward. |
| Resize… | Expands Width and Height controls beside the image, with Keep aspect and Smooth or Nearest resampling. Apply Resize preserves UV placement and supports Undo. Cancel keeps the current image. Save Paint and the scene afterward. |
| New image px | Sets the square image size used by Make Unique when the material has no artwork. For existing artwork, the read-only Texture px field shows its width. |
| Color, Radius, Opacity | Sets the pixel brush. Radius is 1 to 64 texture pixels. |
| Show UV | Shows the selected faces' UV outlines over the image. It is off by default. |

The inline hint asks for a face, a common material, or **Make Unique** when the selection is not ready. With an owned Texture, it says to paint on the image or model, then save the paint and the scene.

## Selection

Shown as a collapsed heading in Vertex, Edge, and Face mode. Expand it to reveal the utility commands. Each command works on the current mode's elements.

| Command | Result |
| --- | --- |
| Select All | Selects every element in the current mode. |
| Select None | Clears the element selection. |
| Invert | Swaps selected elements for unselected ones. |
| Grow | Adds the neighbours of the selection. |
| Snap to Vertex | Highlights an actual source vertex, then moves the selection to a vertex clicked on another solid. |

The selection controls above the command rows configure the editor transform gizmo. **Pivot** chooses Selection centre, the last-selected Active element, or a Custom world XYZ position. **Axes** chooses World, Object local, or Selected face orientation. Selected face axes are enabled only for a face selection. **X-ray selection** includes occluded candidates on visible solids and draws selection lines through the solid; hidden nodes and descendants of hidden nodes remain excluded. Tab and Shift-Tab cycle overlapping candidates.

## Loop cut settings

In Edge mode, **Cuts** sets 1 to 32 evenly spaced cuts. **Centre %** sets the group centre along the starting edge. The group stops before its outer cuts leave the edge. See [Cut and slide edge loops](/guide/how-to/cut-edge-loops).

## Extrude, Inset, and Bevel previews

Starting Extrude, Inset, or Bevel replaces the idle settings with an **active op card**. The card shows the operation title (Extrude, Inset, or Bevel), its settings, and **Cancel | Apply** buttons. **Apply** is primary when the current values produce valid geometry.

**Extrude** opens **Extrude distance** (−64 to 64). Positive distance extrudes outward along the face normal; negative distance extrudes inward. **Inset** opens **Inset distance**. **Bevel** opens **Bevel width** and **Segments** (1 to 16).

The 3D view renders the proposed geometry while the original solid remains unchanged. The coloured viewport handle changes the operation's numeric value. Enter or **Apply** commits one undo action. Escape, right-click, or **Cancel** restores the original display and leaves the solid unchanged. If a value would make invalid geometry, Slab restores the original solid and disables **Apply**.

Saving the scene while a preview is open does not save the proposed geometry, and the preview stays active. Apply the operation, then save the scene to keep the result.

Extrude, Inset, and Bevel each remember their own last-used distance for the editor session. Cancelling retains that operation's setting for the next preview. Undo restores geometry; it does not change these session preferences.

**Plane Cut** exposes local normal, offset, retained side, cap material, Apply, and Cancel. **Array** exposes Linear or Radial mode, a total Count from 2 to 256, and parent-local placement fields. Snap and Align show the current target instructions; Align also lets you choose whether the face normals oppose each other.
