# The Slab panel

The panel is the bottom dock named **Slab**. It is a command toolbar. Object mode shows Create and Object. Vertex, Edge, and Face each show their own group and Selection. Commands have icons and labels. The tooltip holds the name, what it does, and the shortcut. A command disables when the selection count is too small. The tooltip then states the missing requirement.

The header status line repeats the selection, for example `Box, 1 face.`

## Settings strip

Under the commands. Click **UV** beside Distance to show the UV fields. The fields follow the mode, and in Object mode they follow the Create icon you last hovered.

| Field | When it shows | Role |
| --- | --- | --- |
| Width, Height, Depth | Object, on the focused Create icon | Size for that click. |
| Steps, Sides, Segments, Thickness, Arc | Object, when Stair, Cylinder, or Arch is focused | Only the params that shape reads. |
| Amount | Vertex, Edge | Distance for Bevel and Weld. Default 0.5; range 0.05 to 64. |
| Distance | Face | Distance for Extrude and Inset. Default 0.5; range -64 to 64. Extrude keeps the sign. Inset uses the absolute value. |
| UV scale, offset, rotation | Face | Written by Apply UV. Rotation is degrees on the panel. The solid stores radians. |
| Pixels / metre, Texture px | Face, with UV open | Set the physical density and normalization used by Unwrap. |
| Material chips | Face, with a solid selected | Click a chip to pick the paint. The plus chip appends a material. **Set Material** writes that index onto the faces. |

## Create fields

Object mode. Hover a Create icon to see its fields. Changing a field never rewrites a solid that already exists.

| Field | Default | Range | Read by |
| --- | --- | --- | --- |
| Width | 2 m | 0.05 to 64 | Every Create command. Cylinder reads it as diameter. Arch reads it as the outer sweep diameter. |
| Height | 2 m | 0.05 to 64 | Box, Stair, Cylinder, Poly Shape, Curve Sweep. Plane and Arch ignore it. |
| Depth | 2 m | 0.05 to 64 | Every Create command except Cylinder. Curve Sweep uses it as path length. |
| Steps | 8 | 1 to 32 | Stair. |
| Sides | 16 | 3 to 32 | Cylinder. |
| Segments | 8 | 4 to 32 | Arch. |
| Thickness | 0.25 m | 0.05 to 8 | Arch. Must stay under half of Width. |
| Arc | 180° | 15 to 360 | Arch. Sweep centered on the crown. |

**Arc.** At 180° you get a half tube as wide as Width, both feet on the floor. Below 180° the band is narrower than Width and shorter than that half-tube. Above 180° you get a horseshoe. At 360° the ends join into a closed ring. Height is not an input. It follows Width and Arc.

## Create

Object mode. No selection required. Hover a Create icon, set its fields, then click.

| Command | Result |
| --- | --- |
| Box | A box of Width × Height × Depth at the origin. |
| Plane | A Width × Depth slab one grid step thick. |
| Stair | A straight run of Steps steps. |
| Cylinder | A cylinder with Sides sides. Width is the diameter. |
| Arch | A thick band swept through Arc. Width is the outer diameter. Depth is the extrusion. |
| Poly Shape | A Width × Depth square extruded to Height. |
| Curve Sweep | A Width × Height profile swept along a path whose length follows Depth. |

See [Create a solid](/guide/how-to/create-a-solid).

## Object

Needs a selected `SlabSolid`. Union, Subtract, and Intersect need two. The first selected solid is the host. The second is the other operand.

| Command | Result |
| --- | --- |
| Union | Adds the second solid into the first. |
| Subtract | Cuts the second solid out of the first. |
| Intersect | Keeps only the overlap. |
| Mirror X, Mirror Y, Mirror Z | Mirrors across that local axis. |
| Center Pivot | Moves the origin to the middle of the solid. |
| Snap To Grid | Rounds every vertex onto the grid step. |
| Plane Cut | Previews an exact local-space plane, keeps the chosen side, and caps every section loop. |
| Array | Previews 2 to 256 total instances in a linear or radial layout, then creates the copies as one undo action. |

## Vertex

| Command | Needs | Result |
| --- | --- | --- |
| Weld | 2 vertices | Merges vertices closer than Amount. |
| Collapse | 2 vertices | Collapses the selection to one vertex. |
| Connect | 2 vertices | Cuts an edge between the selected vertices. |

## Edge

| Command | Needs | Result |
| --- | --- | --- |
| Bevel | 1 edge | Previews an Amount-wide bevel. Segments 1 is a chamfer; 2 to 16 form a rounded profile. |
| Bridge | 2 edges | Builds a face between two open edges. |
| Connect | 2 edges | Cuts a new edge between edge midpoints. |
| Loop Cut | Edge mode | Previews cuts through a quad strip. Click to slide, wheel to change count, type a percentage, Enter to apply. |
| Dissolve | 1 edge | Removes the edge and merges its faces. |
| Select Loop | 1 edge | Follows the edge loop around the solid. |
| Select Ring | 1 edge | Follows the parallel edges across quads. |
| Mark Seam | 1 edge | Marks selected edges as UV island boundaries. |
| Clear Seam | 1 edge | Removes UV seam marks from selected edges. |

## Face

| Command | Needs | Result |
| --- | --- | --- |
| Extrude | 1 face | Pulls one face along its normal. A connected selection moves as one region and builds walls only around its boundary. |
| Inset | 1 face | Shrinks one face, or a connected coplanar selection inside its shared boundary. |
| Delete | 1 face | Deletes the selected faces. |
| Flip Normals | 1 face | Reverses which way the faces point. |
| Subdivide | 1 face | Splits each face into four. |
| Merge | 2 faces | Joins coplanar faces into one. |
| Set Material | 1 face | Assigns the active material chip to the faces. |
| Apply UV | 1 face | Writes the UV scale, offset, and rotation fields. |
| UV Larger | 1 face | Doubles the UV scale and applies it. |
| UV Smaller | 1 face | Halves the UV scale and applies it. |
| UV Rotate | 1 face | Turns the UV by 90 degrees. |
| UV Reset | 1 face | Returns the UV to scale one and no rotation. |
| Align Face | 1 face | Previews a rigid transform that seats the selected face on a face clicked on another solid. |
| Unwrap | 1 face | Unfolds the selected region at the requested density using marked and automatic seams. |

Albedo and UV steps are in [Texture a room](/guide/tutorials/texture-a-room).

## Surface Paint

**Surface Paint** in the header opens a separate workspace and switches to Face mode. Escape closes it. **Material / UV** assigns materials and places the selected face on the texture. **Pixel** paints the active material's albedo on the canvas or directly in the 3D view.

| Control | Result |
| --- | --- |
| Make Unique | Copies the active material, assigns the copy to the selected face, and makes its albedo editable. |
| Save Paint | Writes `res://slab_paint/<solid>_m<slot>.png`. Save the scene afterward. |
| Sample | Reads the selected face's material and UV. Alt-click a face in the 3D view does the same. |
| Material picker | Adds or selects a `StandardMaterial3D` and assigns it to the selected face. |
| Repeat U, Repeat V | Sets texture repeats from 0.05 to 64. |
| Offset U, Offset V | Moves the texture from -64 to 64. |
| Rotation | Sets rotation from -360° to 360°. |
| Apply UV | Writes the numeric UV values to the selected face. |
| Reset UV | Returns repeats to one, offsets to zero, and rotation to zero. |
| UV 90° | Adds 90° and applies it. |
| Color, Radius, Opacity | Sets the pixel brush. Radius is 1 to 64 texture pixels. |

On the UV canvas, drag to move, Shift-drag to scale, and Ctrl-drag to rotate. Use Cmd-drag to rotate on macOS. Scroll zooms and middle-drag pans. See [Paint texture pixels](/guide/how-to/paint-texture-pixels).

## Selection

Shown in Vertex, Edge, and Face mode. Each command works on the current mode's elements.

| Command | Result |
| --- | --- |
| Select All | Selects every element in the current mode. |
| Select None | Clears the element selection. |
| Invert | Swaps selected elements for unselected ones. |
| Grow | Adds the neighbours of the selection. |
| Snap to Vertex | Highlights an actual source vertex, then moves the selection to a vertex clicked on another solid. |

## Loop cut settings

In Edge mode, **Cuts** sets 1 to 32 evenly spaced cuts. **Centre %** sets the group centre along the starting edge. The group stops before its outer cuts leave the edge. See [Cut and slide edge loops](/guide/how-to/cut-edge-loops).

## Modal settings

**Plane Cut** exposes local normal, offset, retained side, cap material, Apply, and Cancel. **Array** exposes Linear or Radial mode, a total Count from 2 to 256, and parent-local placement fields. **Bevel** exposes Amount and 1 to 16 Segments. Snap and Align show the current target instructions; Align also lets you choose whether the face normals oppose each other.
